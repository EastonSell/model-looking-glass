# Natural transfer launch boundary

These source-bound components implement the direct-child observer, CPU phase caller and public-only input comparison for the fixed natural invariant-noun transfer successor. The protocol and addendum describe the candidate schedule and analysis. Currentness compares all 612 input/answer forms with every foreign expanded public inventory form in both prefix directions, exempting only validated own reservation IDs. It also checks the fixed France and paired-copy pending bundles and their declared continuations when present. Public comparisons do not establish private, unknown or pretraining exposure.

Before loading the model the caller checks the complete baseline's separate cooperative owner/supervisor exit, child custody, file inventory, entry, source, model admission, terminal and independently checked saved-byte audit. It validates the already-completed audit's original and path-redacted observations, their exit, before/after evidence and reviewed reader hashes, and exact report bindings; it does not repeat that audit. The model-free target reader then checks each saved receiver vector and full logits. Baseline and transfer source identities are distinct. The pre-patch vector equality does not prove that baseline logits would be identical in the new process.

The evaluation caller recomputes the exact discovery freeze from closed saved evidence before loading a model, and checks concrete discovery exit and terminal fields. Immutable public freeze readback and timing are separate cooperative observations. Direct-child receipts do not attest descendants or every instruction; an absent receipt or uncertain child state is incomplete and must be reconciled before any retry.

The explicit `natural_transfer_check_currentness.py`, `natural_transfer_check_baseline.py`, `natural_transfer_check_phase.py` and `natural_transfer_check_direct.py` tests use the fabricated-only environment described in `README.md`, plus `NATURAL_INVENTORY` for a reviewed public inventory, `NATURAL_PENDING_FRANCE` for the tokenizer-only France bundle and `NATURAL_PENDING_COPY` for the tokenizer-only paired-copy bundle. They are not collected by the default pytest filename pattern. No pretrained transfer result is asserted by the tests. A public pre-run must bind the completed baseline, exact source and input identities, current public comparisons, and resource observations before discovery; a separately public discovery freeze is required before evaluation.
