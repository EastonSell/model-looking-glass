# Natural transfer launch-boundary draft

This draft contains a bounded direct-child observer, a CPU phase caller and a public-only input comparison for the natural invariant-noun transfer successor. The fixed cases, Q mapping and design are described in the published protocol and successor addendum. Currentness checks compare all 612 input/answer forms against every foreign expanded public inventory form in both prefix directions, exempting only validated own reservation IDs. The separately fixed France pending bundle is checked in the same way, including its declared continuations. Public comparisons do not establish private, unknown or pretraining exposure.

The evaluation caller recomputes the exact discovery freeze from closed saved evidence before loading a model, and checks concrete direct-child exit and terminal fields. The immutable public freeze readback and timing are separate cooperative observations. Direct-child receipts do not attest descendants or every instruction, and a missing receipt means uncertain process state, not permission to retry.

**This snapshot is not a launch authorization.** The fresh successor baseline is in progress. The baseline audit file is currently checked only by its pinned hash; a successor must validate the actual independent audit's successful status, case/schedule/model/source and receipt bindings once its closed schema is available. The final public pre-run must separately pin the reviewed baseline and transfer sources, closed baseline receipt and audit, model assets, latest public inventory comparison, any pending bundles and resource checks before discovery. The evaluation phase additionally needs the public discovery freeze and its independent readback.

The explicit `natural_transfer_check_currentness.py`, `natural_transfer_check_phase.py` and `natural_transfer_check_direct.py` tests use the same fabricated-only environment described in `README.md`, plus `NATURAL_INVENTORY` for a reviewed public inventory and `NATURAL_PENDING_FRANCE` for the tokenizer-only France case bundle. They are not collected by the default pytest filename pattern. No pretrained transfer result is asserted by these tests.
