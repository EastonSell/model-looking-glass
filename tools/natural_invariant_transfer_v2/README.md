# Natural invariant-noun transfer: component snapshot

These components implement the separately preregistered fixed-site transfer and successor addendum in `docs/NATURAL_INVARIANT_DONOR_TRANSFER_V1.md` and `docs/NATURAL_INVARIANT_DONOR_TRANSFER_SUCCESSOR_V2.md`. They are a scientific executor and model-free saved-byte readers, not a complete launch authorization or a pretrained result. The prior reader requires a **complete** separately reviewed successor baseline; the stopped first attempt is not a baseline for this study.

`natural_transfer_numeric.py` forms Q1–Q4 replacements and exact rational dose certificates. `natural_transfer_executor.py` checks the actual receiver vector at the hook and records full landing witnesses and displacement bytes. `natural_transfer_analyze.py` replays the saved patches and passes only an anonymous finite 24-by-4 numeric matrix into selection. `natural_transfer_freeze.py` recomputes a discovery freeze before evaluation, but cannot itself establish that the given public commit was actually observed. The phase caller must independently verify the complete prior receipt/audit, distinct prior and transfer source and model identities, current exposure, disk limits, and exact public freeze readback; record those observations before the corresponding forward. A missing or uncertain receipt remains incomplete and is never an automatic retry.

The source was fabricated-tested with the repository's `looking_glass` dependencies at public commit `f2239d43d528366a6acc1a87a78c328a86124ad5`, including `intervention_plan.py` Git blob `db044faa4e547a96278607efabca82ea4aa14384`. These are the transfer dependencies, not a claim that the eventual baseline used identical source bytes. No real model was used for the component tests.

The explicit `natural_transfer_check_*.py` scripts use a separately generated 612-action, 8-wide/1500-vocabulary **toy** prior and its 192-action toy transfer fixture. They are intentionally not discovered by the default pytest filename pattern. Set `INVARIANT_TEST_OWNER_SOURCE` to the checkout containing `tests/test_agreement_invariant_executor_v1.py`, `NATURAL_RUNTIME_SOURCE` to the source checkout whose intervention dependencies are being tested, `NATURAL_TOY_JOURNAL` to the complete toy prior, `NATURAL_CASES` and `NATURAL_MAPPING` to the frozen public successor cases and mapping, `NATURAL_TEST_TEMP` to a writable scratch directory, `NATURAL_FAKE_FIXTURE` to the generated toy transfer fixture, and `NATURAL_TOY_SCHEDULE_SHA` to `f0625d27ee196eeeb1a85a3577238f0cbcad19017fc6596dfe429dcbc60c610d`. Run each check from this directory with `python -B natural_transfer_check_<name>.py`. `generate_natural_transfer_fixture.py <new-directory>` creates the toy transfer fixture from that toy prior; it must never be presented as pretrained evidence.

Discovery uses 96 patches; the exact selected candidate and all signed predictions must be frozen and publicly read back before the separate 96 evaluation patches. Q2's identity is public by construction. Movement toward the opposite-number donor is donor-consistent transfer and may worsen the recipient's own grammatical prediction; it is not automatically rescue. The primary outcome is conditional on cross-process baseline-logit stability and does not establish a circuit.
