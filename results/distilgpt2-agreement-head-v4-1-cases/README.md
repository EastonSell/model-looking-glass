# Corrected fresh-context agreement-head cases

The [v4.1 protocol](../../docs/DISTILGPT2_AGREEMENT_HEADS_FRESH_CONTEXT_V4_1.md) fixes 16 public, nonblind cases before a model forward. This supersedes the unforwarded original v4 case manifest: three of its subject lemmas appeared in earlier exposed head-development rows. The corrected four lemmas are absent from the earlier head-study development and evaluation cases; this does not claim absence from other model inputs or pretraining. Frames, donor mapping, 5%-of-receiver dose, controls and fixed comparison criteria are otherwise unchanged.

This package records tokenizer-only preparation and historical public comparisons. It is not a model result or an exposure reservation. The 16 base rows are proposed model inputs; their four declared one-token answer continuations are included for public overlap checking and would be read from final-position logits rather than forwarded as appended inputs.

## Tokenizer and prior-case checks

Run `scripts/prepare_agreement_head_v4_1_fresh_cases.py` with explicit `--snapshot`, `--protocol` and create-only `--output` paths. It verifies the fixed protocol and tokenizer asset SHA-256s, requires `tokenizers` 0.22.2, checks quartet structure and continuation tokenization, and loads no model. Normal and optimized runs both produced case SHA-256 `bfc93dbcf33f06c8266b0fabf351dfa9f17ab98d6501ca7380e2cd171bddc8b4`.

`prior-lemma-check.json`, generated by `scripts/check_agreement_head_v4_1_prior_lemmas.py`, compares the corrected subjects with the 16 public development records in the v43 inventory and the 16 fixed v2 evaluation cases. The checked sets are limited to those prior head-study cases; no model or private query is involved. An independent reviewer also retokenized all 80 sequences and verified the prior-lemma comparison.

## Public overlap checks

- `public-overlap-v43.json` compares all 80 corrected base/continuation sequences with 6,297 distinct sequences reconstructed from the v43 canonical inventory (SHA-256 `61a80aafd9d4aea075774776d830b017f8e4c5e1a4fd0f2643963d2075a6e4ee`) and 612 sequences from the invariant-noun successor case file (SHA-256 `188782606abd576cde029408bb34975e7fd7ac2113bf17299dbb7e1aa2ddd76b`). No complete-row-prefix relation exists in either direction. `scripts/check_agreement_head_v4_1_public_overlap.py` reproduces the comparison from explicit files and can bind a later inventory digest via `--inventory-sha256`.
- `france-public-overlap.json` compares the same 80 sequences with 73 sequences in the separately owned pending France proposal, SHA-256 `c8dd418bea948c8ca2b4d1e39e696374a28bd2f911bb16707415c38170fbba82`; no prefix relation exists in either direction. The receipt does not assert that those France rows were forwarded. The checker can reproduce this optional comparison when supplied that exact manifest.
- `natural-public-support.json` checks both the corrected head cases and the invariant successor against the public 128-row original natural support, 256-row successor pool, six short-service rows and public timing input, and checks the two case sets against one another. It retokenizes all declared continuations. Counts are zero. `scripts/natural_public_cases_crosscheck_v3.py` takes explicit paths to the pinned public files; the original-split inference remains conditional on its recorded sampler, custody and tokenizer preparation.

These are point-in-time public-only checks. They do not establish complete exposure history, unknown pretraining independence, private split membership or any model behavior. Refresh the official inventory, pending proposals and applicable custody observations and publish a planned-only reservation before a model run. L3H4 and the H8 comparator were chosen adaptively on earlier exposed development data; singular/plural donor forms are different lexical tokens, and the repeated frames and lemmas are not independent samples.
