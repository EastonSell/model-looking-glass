# FLAN-T5 targeted input-row edit: development

This is the development phase of a predeclared two-phase study. **There is no held-out target or locality result yet.** The original eight discovery/calibration target and donor inputs passed their strict clean-label and full-sequence baseline gates.

The intervention replaced the shared input embedding for `wonderful` with the exact `awful` row. It made all four development target outputs strictly `negative`. On the two calibration wordings, the gains in negative-versus-positive sequence margin were +11.58335 and +9.72395; the gains in negative-label sequence log probability were +5.97372 and +5.12881. These are two wordings about the same movie, not independent examples.

The broader output-head control met the fixed per-case calibration match at dose 2.0. The random and opposite input-row controls did not meet that match; their predeclared nearest grid point was 4.0. Those unmatched controls are retained for descriptive evaluation and must not be called efficacy-matched. The independent reader's [full grid and selection](independent-reader.json) and a [second saved-logit audit](independent-science.json) retain every calibration value.

All 16 comparable primary-to-clean-donor logit spans and four generated sequences matched. This is the expected mechanical substitution for aligned encoder inputs and matching decoder prefixes that omit the edited token; it is not evidence that a general sentiment concept was edited. The LM head is separate from the shared encoder/decoder input embedding.

The closed phase records 370 model calls. The fixed supervised child exited 0, and all 740 recorded before/after disk observations passed. All 29 restoration-probe rows matched the initial probe; row/state/buffer hashes are cooperative model-authored observations rather than independent measurements of live memory. The [independent process and custody audit](independent-process.json) and [outer operator observation](outer-observation.json) describe the limits of those records.

The [events](events.jsonl), [results](result.json), [resource observations](resources.jsonl), [phase record](phase.json), logs, source-bound manifest and [ordered logit parts](logit-parts.json) preserve the full development evidence. The two token-present localities are reported separately. No general capability or learned selective-edit claim follows from this development phase.
