# Code of conduct

Help make this project a place where people can ask questions, disagree and contribute without being harassed.

- Be respectful of different backgrounds, abilities and experience levels.
- Critique ideas and code, not the person. Give specific, constructive feedback.
- Do not harass, threaten, discriminate, share someone else's private information, or use sexualized language or imagery.
- Respect requests to stop unwanted contact and keep discussions relevant.

This applies to project issues, pull requests and other project-managed spaces. Maintainers may edit or remove content, close discussions, or restrict participation when needed. Apply these expectations consistently, including to maintainers.

For a conduct concern, ask a maintainer for a private contact route without posting personal details publicly. For abusive GitHub content, you can also use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Do not use the vulnerability-reporting form for conduct reports.
