# Accessibility

The interface should work without relying only on color, precise pointer movement or the 3D view. Accessibility is ongoing work; this project does not claim a verified WCAG conformance level.

## Report a problem

[Open a bug report](https://github.com/EastonSell/model-looking-glass/issues/new/choose) with the task you were trying to complete, what blocked you, and your browser or assistive technology if useful. You do not need to disclose a disability or medical information.

## When changing the UI

- Use native buttons, labels and inputs. Give controls understandable names.
- Keep controls keyboard reachable, focus visible, and focus order sensible.
- Preserve the list alternative to the 3D canvas and readable text output.
- Do not communicate a result by color alone.
- Check contrast, zoom, narrow layouts and reduced-motion behavior.
- Describe the checks you actually performed; a screenshot alone does not verify keyboard or screen-reader access.

For contribution steps, see [CONTRIBUTING.md](CONTRIBUTING.md).
