# Public distractor-repair exposure reservation v38

This successor adds the 16 fixed full-input rows from the [public distractor/downstream-repair cases](../experiments/public_distractor_repair_cases_v1.json) as planned records. The model will score at the penultimate-token prefix; its two candidate tokens are not continuations of the full period-terminated input. To preserve the correct exclusion boundary, the successor also adds 32 explicitly `reference-only` rows consisting of each scored prefix followed by token 318 or 389. These are comparison alternatives; no separate model forward is asserted for them. The scored prefix itself is already a prefix of its planned full input.

The predecessor is v37 (canonical SHA-256 `c84d0b83ede1f526215898ce0c2f4f5bdd9c78c8cfeb3f2aced75faaa33fdf6b`). V38's canonical SHA-256 is `f3a500dc02d85b8f004275ba2edd74febf9cec138e83755568e5be31045898a9`; its 1,167 records preserve all 1,119 predecessor records in order and add 16 planned plus 32 reference-only records. The nonempty prefix union is 6,725. The exact public case SHA-256 is `811a1f0251ff21ddaa1869ee96c80dfa47beb87a6b6c2f1e3b6505728fee1825`, with eight discovery and eight held-out inputs; no new distractor-study forward is asserted.

The public [comparison](../experiments/public_distractor_repair_v1/public-comparison-v37.json) checks all 64 full inputs, scored prefixes and scored-prefix continuations against 4,950 v37 public sequences and 1,920 public support sequences in both complete-row-prefix directions: 439,680 pairs, no relations. It also checks all 1,920 cross-case proposal pairs. Tests reconstruct the predecessor, preserve every old row and check that each reference alternative, its shorter prefix and a longer extension are rejected by the public exclusion API. The comparison is public-only; it does not query the old protected split or certify unknown outside/pretraining exposure.

Statuses inherited from earlier snapshots are historical labels, not proof that a previously reserved row remains unforwarded. In particular, the 54 v35 noun-substitution inputs have since been reported as completed with public evidence in [the separate result](../results/distilgpt2-agreement-noun-substitution-study-v1/README.md); this planned/reference-only successor does not change those statuses.
