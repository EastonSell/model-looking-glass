# FLAN-T5 matched-dose response with equal-length targets: public CPU protocol

This is a separate, prospective exploratory study. The preceding fixed six-cell dose-response study ran 36 clean/context forwards: all six cells were baseline-unsupported and no interventions ran. Its outcome motivated controlling a target-token-count asymmetry but does not show that the asymmetry caused those unsupported baselines. Preserve and publish that result separately. The examples here are public and are neither blind nor independent of unknown pretraining exposure. No pretrained forward on the cases below has been made when this protocol was prepared.

## Fixed selection and question

At the final encoder layer-normalization output, does a word-position replacement produce a donor-directed two-target score-margin response that increases with dose and exceeds the responses at two matched control positions? This is a finite-example operational hypothesis, not a statistical significance test or a claim that a unique translation mechanism is localized to a word position.

Use `google/flan-t5-small` revision `0fc9ddf78a1e988dac52e2dac162b0ede4fd74ab` and seven-file asset-manifest SHA-256 `d369e3095dc35c52608f40fbd2715d7a2ff80a02fd71f0692c24af2cf3402083`. The local tokenizer-only selection plan, fixed before tokenizing any candidate, is SHA-256 `1fa773268a2bbfd73979c2ce9f83f6a1d821f6607c37c12460b2368b2ca0668c`. Its 16 ordered candidate pairs, exact Unicode texts and eligibility rules are part of the record. Select the first six that satisfy the same alignment rules in both templates and whose two distinct German targets each tokenize as exactly one lexical token plus EOS. Inspect and retain all 16, including rejected and later eligible candidates; no model outputs or previous case margins enter selection. If fewer than six qualify, retain `selection-incomplete` and run no model. After selection, never replace an unsupported, ineligible or failed case.

## Scores and baseline gate

For each eligible cell run the context-only and both source sentences against both targets without intervention hooks. For target IDs `y`, use decoder IDs `[0]+y[:-1]`, all-one decoder mask and full EOS-inclusive teacher-forced score `S(y)=math.fsum(float32_log_softmax(logits)[position,target_id])`. Save full logits, selected token values, target length and decoder inputs. Let `m(source)=S(first target)-S(second target)` and `Δ=m_A-m_B`. Context-only scores are descriptive prior/context measurements, not a causal correction; the question template's context-only prompt omits the question mark along with the word, so it is not an otherwise identical no-word control.

A cell is baseline-supported only if `m_A>0`, `m_B<0` and `Δ>=1.0` nat. Otherwise retain `baseline-unsupported`, all six clean/context forwards and their scores; skip patches for that cell and continue with the unchanged fixed cases. This outcome does not establish whether greedy generation would translate the word correctly.

## Matched-dose intervention and decision

Obtain unpatched encoder states independently of decoder target and require the copies for each source to match bit-for-bit. For site `s` in {word, instruction, punctuation}, compute the binary64 L2 distance `d_s` between the saved float32 source A and B vectors at that position, and set `q=min_s d_s`. If `q/3<=1e-6`, retain `dose-ineligible` and run no patches for that cell. The exact fractions are `f_0=0`, `f_1=1/3`, `f_2=2/3`, `f_3=1` evaluated in binary64. For each nonzero level, receiver and site, replace with `float32(own+(f_j*q/d_s)*(donor-own))`, using binary64 intermediate operations and one final float32 cast; never extrapolate.

For every one of the three nonzero levels, verify all six actual float32 displacements against `q_j=f_j*q`. Each must be strictly positive and within `min(max(1e-5,1e-5*q_j),0.01*q_j)` of `q_j`; for each receiver, each control's actual dose must be within 1% of that receiver's actual word dose. If any check fails, retain the proposed vectors and `dose-unmatchable` and skip patches for the cell. Record q, the natural distances, all target/achieved doses and receiver norms.

Run each word, instruction and punctuation replacement at all nonzero levels for both receivers and both targets. Define donor-directed movements `w_A(j)=m_A-m_A,word(j)` and `w_B(j)=m_B,word(j)-m_B`, and define signed `c_instruction` and `c_punctuation` analogously. Set movements at `j=0` to zero: the unhooked clean reference, without another forward.

A supported and matchable cell is **positive** only if both receiver directions satisfy all three rules:

1. `w(j+1)>=w(j)-0.0001` nat for `j=0,1,2`.
2. `w(3)>=0.05*Δ` nat.
3. For `j=1,2,3`, `w(j)>=max(abs(c_instruction(j)),abs(c_punctuation(j)))+0.02*f_j*Δ` nat.

The cell is **negative** if any inequality fails. Record every applicable reason: `reversed` for any nonzero word movement below `-0.0001` nat; `nonmonotone` if an adjacent step decreases by more than `0.0001` nat; `weak_endpoint` if rule 2 fails; and `control_comparison` if rule 3 fails. These may overlap. Boundaries follow the written inequalities. Save all signed and absolute movements and individual check results, including negative values. The 0.05 and 0.02 gap fractions are fixed minimum operational effects, not calibrated null distributions or significance thresholds; 0.0001 nat is an ordering tolerance.

Both templates of a lexical pair must be evaluable. The pair is positive if both cells are positive, negative if at least one is negative, and otherwise unevaluable. Let P and N be counts of positive and negative evaluable pairs, respectively. The six-pair aggregate is positive if `P>=3 and P>N`, negative if `N>=3 and N>P`, and otherwise inconclusive, including ties or too few evaluable pairs. This is a strict majority among evaluable pairs with a minimum of three agreeing pairs; it is not a majority of all six when some are unevaluable. Retain every cell and pair status regardless of the aggregate.

## Controls, bounds and interpretation

Keep unhooked clean references, nonmutating Looking Glass capture repeat, null word action, token-self patches at all three positions, full-state self, full-state donor swap, full natural word-position donor swap, and word zero action, each in both directions and for both targets. The natural word swap is a descriptive anchor and may exceed the matched dose. Require exact full-logit equality of clean/repeat/null/self and of full-state swap/donor. Use the ordered same-forward capture/action/capture path. Save pre-action and post-action witnesses and verify the selected position and every untouched encoder position bit-for-bit. Verify hook removal and parameter/buffer/source/asset identity before and after, with a captured clean repeat after interventions. A model, control, identity or evidence failure makes the attempt incomplete; it is not a negative cell.

At most 936 root forwards are permitted: 12 cells times 6 clean/context, 36 intervention anchors/control forwards (including the terminal capture repeat), and 36 matched-dose forwards. Run CPU float32, one thread, deterministic eager attention and offline cache with CUDA hidden; require `MKL_CBWR=COMPATIBLE`, `OMP_NUM_THREADS=1`, `MKL_NUM_THREADS=1`, `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1`. Record the runtime and a separately observed process exit. Start a fresh process with `-B -X pycache_prefix=<fresh-empty-directory>` and verify that prefix before and after. Use a quiescent checkout and a public immutable source-observation JSON that binds the published source, URL and source hashes; the observation is not a trusted timestamp or independent proof of execution. Before weight loading require at least 1 GiB free on the output filesystem; cap all retained run evidence, including bounded failure/partial records, at 512 MiB. Verify a conservative fixed-shape bound including full logits, states, witnesses and failure reserve before the run. Preserve the raw returned bounded tensors, metadata and control evidence; do not copy the checkpoint into the result.

Equal target token counts remove one score-length asymmetry, but do not equalize lexical priors or show why the preceding study was unsupported. Scores include EOS and are teacher-forced sequence log probabilities, not greedy decoded translations. Equal L2 is not equal functional perturbation, and neither positive nor negative results establish a unique lexical mechanism or generalization beyond these fixed public inputs, layer, doses and rules.
