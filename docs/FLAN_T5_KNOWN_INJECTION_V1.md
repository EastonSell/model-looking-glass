# FLAN-T5 known-injection localization: public protocol

This is a small instrumentation study, not an explanation of naturally occurring model behavior. It asks whether a paired trace identifies an artificial, explicitly introduced state change in either T5 stack and whether putting back the clean state at that site restores the teacher-forced output. It compares first-change localization with maximum trace displacement and a fixed pseudorandom guess. No model output from these eight cases was used to choose the cases, sites, perturbation, baselines, or comparisons. They are public and may occur in model pretraining; the held-out label means only the separately fixed second group was not used for local development.

## Fixed trace, injection, and baselines

The pinned checkpoint has eight encoder and eight decoder blocks. For each case, record only encoder block outputs at batch 0/source token 1 for layers 0–5, followed by decoder block outputs at batch 0/decoder token 1 for layers 0–5; layers 6–7 in each stack are unobserved. These twelve selected coordinates are in execution order, with an unobserved two-block gap between the encoder and decoder selections. First-change and magnitude rankings are restricted to these coordinates. Token coordinates refer to different local tensors and need not align semantically. In the pinned tokenization, encoder token 1 is the final `e` of `Archive` for every discovery case but ` label` for every held-out case; it is not either variable word. Thus split comparisons do not intervene at the same lexical location. Captures are selected vectors after each entire block; decoder blocks already include cross-attention. Check that both positions are active and non-EOS. Each block output is the first tensor in its output tuple. Record exact path, invocation, tensor shape, masks, IDs, and the effective post-intervention captured bits.

Run the same input twice clean to check deterministic repeat, and for each stack run a separate injection at that stack's layer 2/token 1. In the clean float32 vector, replace component 0 with the binary32-rounded sum `float32(clean[0] + 4.0)`; all other components and all other token positions remain unchanged. Retain the actual bits and realized L2 displacement. Fail that trial if the result is nonfinite or the realized displacement is zero. The target and input are chosen before any output; there are sixteen case-by-stack injection trials. Discovery and held-out results are reported separately, with eight trials in each, and no selection or retuning based on either group's results.

Compare the clean and injected effective vectors at all twelve coordinates. The **first-change** guess is the earliest coordinate whose float32 bits differ; it is expected to be the injected stack/layer. The **magnitude** guess is the largest L2 change across coordinates, computed from retained float32 values in double precision; exact ties break by the declared execution order. For fixed random guesses, compute `h = SHA256(('FLAN-T5-known-injection-random-v1|' + case_id + '|' + stack).encode('ascii'))`. The across-stack guess is `int.from_bytes(h[:8], 'big') % 12`; the given-stack guess is that stack's first index (0 for encoder, 6 for decoder) plus `int.from_bytes(h[8:16], 'big') % 6`. Both ignore model outcomes. Also report the trivial given-stack constant guess at layer 2, which is 16/16 correct by construction because the protocol discloses the injected site. Report the chosen site and exact-hit result for every trial, per-split/per-stack counts and the full displacement vectors. The across-stack random baseline guesses over more possibilities than a method told the target stack. A random guess can accidentally be correct; no significance test or guaranteed result is claimed.

## Restoration and controls

For each injected trial, run three further arms on the identical encoder/decoder inputs: (1) a same-site self patch copies the already injected vector back to itself and should reproduce the injected traces and logits bitwise; (2) a same-site clean-state replacement copies the clean layer-2 vector immediately after injection and is predicted to restore the clean selected traces and full teacher-forced logits bitwise; (3) an alternate-site comparison replaces the same token at the same stack's layer 3 with its clean layer-3 vector after the injection. The same-site replacement immediately undoes the injected vector by construction, so its restoration is a mechanics check. The alternate-site patch must report its realized L2 displacement and is marked inactive if that displacement is zero. It can restore the output, partly restore it, or have another effect; it is an active comparison, not a negative control or proof of site uniqueness.

Retain complete pre/post module-output tensors for every patch, the clean and injected source vectors, full logits at both decoder positions for every arm, all selected trace vectors, masks and IDs, and ordered action metadata. Verify the requested vector lands bitwise, every other position is unchanged, the self and clean-repeat controls match their references, and all tensors/logits are finite with the expected shapes. Save evidence under content-addressed float32 files with a fixed 32 MiB raw-evidence ceiling; abort without dropping or replacing prior evidence if a bound, source, asset or control check fails. Record the actual IDs/masks and per-forward start, observed wrapper return and completion. A trace wrapper can fail after its internal model call returns, so an unobserved wrapper return does not prove the underlying model failed to return. Retain available partial evidence on interruption and do not rerun a failed trial silently. The final result and completion event are written only after the post-run asset and CUDA checks pass; an independently observed successful process exit is still required for promotion. There are at most 80 forwards: two clean forwards and four arms at each of two sites per case.

The direct first-change result is largely built into this design: the injected coordinate is among the observed boundaries, and all earlier boundaries are expected unchanged. Downstream changes, alternate-site restoration, magnitude rankings, and output effects are model- and input-dependent. This test does not localize a naturally occurring computation, isolate cross-attention, prove hidden-state uniqueness, or establish population-level generalization.

## Pre-forward admission correction

The first published runner loaded the pinned checkpoint but stopped at its dimension guard before creating the study output or making any case forward. It incorrectly expected six total blocks per stack; the pinned configuration has eight. The direct-process observation and a path-free failure record are retained as `docs/FLAN_T5_KNOWN_INJECTION_ADMISSION_FAILURE_V1.json` and `docs/FLAN_T5_KNOWN_INJECTION_ADMISSION_OBSERVATION_V1.json`. This successor corrects that guard and clarifies that blocks 0–5 were always the selected trace coordinates. The cases, selected sites, prediction, comparisons, and evidence limit remain fixed; the process observation is cooperative evidence, not independent proof of every instruction executed.
