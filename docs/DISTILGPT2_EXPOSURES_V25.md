# DistilGPT2 known exposure inventory v25

This successor preserves every v24 input and records two public changes. It
marks the 12 already-reserved screened locality rows observed-saved, and
reserves 48 fixed year/label prompts as planned. It does not assert a
year/label forward. The older sealed natural split was not queried for these
48 prompts; no pretraining or unrecorded exposure is certified.

The locality update binds the fixed screened case inventory and merged
evaluation evidence. Each exact locality ID has one original and six edited
saved rows. `scripts/check_v25_locality_evidence.py` reads the immutable Git
objects, verifies their case identities, phase file and seven full raw-file
hashes, then checks all 84 individual row hashes. The associated clean process
and cleanup reports are cooperative observations, not authenticated proof.
All 12 input token rows and every other predecessor record remain intact;
only their identifiers, statuses and evidence provenance are updated.

The year/label source is the independently reviewed public case file at merge
`469f13747bb90c67cdc3a9a1aa2a867ff69b1616`. The 48 rows and their four
candidate groups are embedded in fixed case order. Their input and candidate
continuation rows were compared in both complete-row-prefix directions against
the v24 known input and continuation inventory and against the separately
published 256-row natural-successor candidate pool, file
`experiments/natural_agreement_successor_inputs_v1.json` at merge
`afdbc15317983a3948116c28eb857c5ddb869783` (SHA-256
`6303eb0713d64b020eea3fe491a686c9020ea424754443372aef73749bc87bc4`).
Both public comparisons passed; neither is an old sealed-split comparison. Each planned record is
marked as such and retains the uncertainty about outside exposure.

The canonical payload SHA-256 is
`32cc4bcbe4b482ded122715c5f96c6c5c765a76a1ef3532360cdf9890827f144`.
It contains 595 records and 4,190 distinct known input prefixes. The prior
3,888-prefix set is preserved. As with earlier versions, known-row checks do
not authorize a study seal or establish a complete exposure history.
