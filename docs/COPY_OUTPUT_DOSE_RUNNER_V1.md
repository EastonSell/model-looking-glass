# Output-dose copying-head runner

This runner executes the fixed [protocol](DISTILGPT2_COPY_OUTPUT_DOSE_V1.md) on the already published 32 cases. It compares single-head interventions at a family-wide matched `c_proj` output norm; the separate input-dose arms are descriptive secondary comparisons. A common norm does not match output direction or downstream nonlinear effects, and H7 is one active control.

For each family, the runner records all four clean/no-op pairs, forms the output and input plans without using target outcomes, and executes the fixed filtered arm order. It checks full pre-input and landing bits, unchanged other positions, actual projected output dose, and the vector residual against the checkpoint-derived projection. It retains full-vocabulary logits and every witnessed input/output. Eligible families require all four variants for that scheme. A bad witness is an incomplete attempt; a finite, correctly landed dose mismatch is ineligible for that scheme.

The stdlib bootstrap checks the committed manifest and source bytes before importing project modules or PyTorch. This is a cooperative operator contract: use the bootstrap, keep the checkout protected from modification until the process exits, and independently retain its process receipt. An environment marker by itself does not authenticate execution. The manifest is the only source-to-HEAD tree change; the process must run in a clean checkout with an empty absolute bytecode prefix, CPU-only/offline settings, and the pinned local checkpoint. Check current public exposure records immediately before the one planned launch; input reservations do not assert unknown or pretraining exposure.

On Windows, supply absolute `CACHE`, `OUTPUT`, `MANIFEST`, `PYTHON`, and a fresh empty `PYCACHE` on a disk with sufficient free space. Set `CUDA_VISIBLE_DEVICES=-1`, `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, and `OMP_NUM_THREADS=MKL_NUM_THREADS=1`; leave `MKL_CBWR` and `ATEN_CPU_CAPABILITY` unset. The documented invocation is `PYTHON -B -X pycache_prefix=PYCACHE scripts/copying_head_output_dose_bootstrap_v1.py --cache-dir CACHE --output-dir OUTPUT --manifest MANIFEST`. `--verify-only` stops before importing the owner or loading a model. The output directory must be new, outside the checkout, and on E:; the owner checks at least 1 GiB free on C: and reserves the bounded E: payload and metadata space.

`manifest.json`, `attempt.jsonl`, one raw float32 stream per case, and the three concatenated H2/H10/H7 projection-weight slices preserve the observed record. The complete result includes per-action scores, full-distribution changes and both decisions. The intended maximum is 288 forward calls and 80,604,288 action bytes, plus 589,824 weight bytes. Journal, result, manifest and failure files have fixed caps. On an exception, the owner attempts to retain returned bytes and writes `failure.json`; partial files and uncertain process state must be preserved, and an incomplete attempt is not automatically retried. A separate process receipt records exit and reaping, not authenticated hardware execution.

The no-model tests exercise the family schedule, rounding and dose gates, witness errors, metadata limits, and fabricated saved-byte fixtures. The synthetic fixture builder deliberately marks its output and uses invented weights; it cannot establish a checkpoint or pretrained-model outcome.
