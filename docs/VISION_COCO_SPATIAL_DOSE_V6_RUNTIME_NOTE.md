# V6 runtime clarification before the clean screen

The annotation-only inventory has been prepared, but no v6 model forward has
occurred. The inherited evidence path retains returned bytes and rejects a
nonfinite logit or captured activation before the dose planner runs. Such a
model return therefore makes the attempt **incomplete**, with available
evidence retained; it is not an evaluable dose-ineligible side. This corrects
the broader nonfinite wording in the original protocol. For finite states,
receiver norm, donor distance or low dose at or below `1e-6` remains
dose-ineligible as specified. The sample, dose ladder, control and decision
rules are unchanged.
