# Paired continuation CPU runner

The runner implements the fixed [prospective protocol](DISTILGPT2_PAIRED_CONTINUATION_PATCH_V1.md) and its [pre-forward pool amendment](DISTILGPT2_PAIRED_CONTINUATION_POOL_AMENDMENT_V1.md). It screens all 64 fixed prompts first; then it runs all 16 families, irrespective of clean support, with four no-op controls, four H2 self patches, the twelve preplanned matched-output-dose patches when the family plan is eligible, and four clean-after controls. A correctly landed actual-dose mismatch is reported as dose-ineligible after all twelve arms. Missing or invalid evidence makes the attempt incomplete.

Each case has an append-only `.f32` stream: every recorded action includes its complete 50,257-float vocabulary row; witnessed actions additionally include all 12×768 float32 projection input-before, input-after and output tensors. The journal binds each segment's offset, byte count and SHA-256, followed by its score and any comparison. `projection-weights.f32` contains the H2, H10 and H7 input-row slices in that order. `manifest.json`, `attempt.jsonl`, `result.json` and any `failure.json` retain execution, family and partial-result information. Recovery of a returned but partly written payload is best effort; a failure or unbound process return is not retry-safe evidence.

The primary threshold is evaluated directly from the saved binary32 candidate logits, including the exact ≥1-nat boundary. Family strict signs use directly combined source terms before display rounding. The result includes all dose-valid, odds-unsupported and odds/top-supported strata separately. Full-vocabulary candidate mass, ranks, tops/ties, KL and total variation are descriptive; a candidate-odds reversal alone is not a generated answer. H7 and H10 are two fixed active comparators. Equal output norms leave different directions, input displacements and downstream nonlinear effects; neither the prompt comparison nor a positive patch establishes a unique copying mechanism.

The stdlib bootstrap verifies the manifest and mapped committed source before importing the project when invoked by the recorded command in an exclusively held checkout; its environment marker is not authentication and a caller can forge it. The operator must protect the checkout for the verification/use interval. The direct-child observer records the caller-supplied public commit, command, environment, exit and file hashes; it does not attest the interpreter, clock, descendants, another process or historical cleanup. Its stdout/stderr files are separate and are not hard-capped by the owner metadata limits. A lost spawn return or unreaped child remains uncertain. Inputs and source are public, but unknown and pretraining exposures are not checked.

The owner enforces the fixed E: staging/output and fresh E:/C: space checks, uses the pinned offline CPU checkpoint, and checks model state, buffers and hook cleanup. Seven verified assets are temporarily staged on E: by the loader; an empty later listing is not independent proof of past cleanup. The full retained streams and checkpoint are needed for an independent raw replay. All outcomes, including unsupported or underfilled ones, must be reported.
