# Year versus label control runner v1

The executor implements the separately published fixed year/label protocol.
It binds the independently reviewed v25 exposure reservation and verifies its
ordered 48 rows and each unique exact planned record before a model load.
The earlier sealed natural split
has not been compared with these cases; unknown prior and pretraining exposure
is not certified.

The runner saves one raw little-endian float32 stream per case. Each complete
record locates and hashes its final-position full-vocabulary logits and, for
hooked forwards, both complete block-output witnesses. It records the planned
site bits before each forward, actual landing and achieved same-invocation
dose, all offsets and signed case effects. The journal records start,
raw-recorded and completion separately. The raw total for the fixed 15-token
cases is 103,736,832 bytes; 133,817,856 is the protocol's 32-token maximum.
Any incomplete attempt retains available bounded payloads and a failure
record. Observation flags and direct process receipts do not independently
attest execution, concurrent activity or descendant processes.

The run is one-shot, offline, CPU float32 with a fixed seed and one intra-op
thread. It records the backend environment before importing Torch, verifies
it during execution, and cooperatively guards CUDA and network entry points.
Launch with `-B -X pycache_prefix=<fresh-absolute-empty-directory>`; the child
checks that the prefix is an existing empty non-symlink directory before its
Torch and project imports and during runtime, and the operator checks it again
after exit. This avoids reading a pre-existing source-adjacent bytecode cache;
it assumes a trusted interpreter and startup environment and is not a guard
against concurrent or native-code tampering. Public records bind only the
SHA-256 of the resolved, platform-normalized local prefix path, not the path
itself; the receipt separately records whether its local path matches and is
still empty after exit.
Its clean, no-op, self and clean-after logits must match bit for bit; every
intervention checks the same-invocation site and all untouched coordinates.
Both input L2 matching and the fixed active label control are limited: they
do not equalize downstream sensitivity or establish a numerical comparator.
All 48 cases run independently of the clean behavior and the result retains
all target effects, controls and failures.

Before any real forward, publish the exact reviewed runner and source-bound
pre-run record, check the latest relevant public inventory and fixed source
bytes, and record the observed identity. Unrelated repository advances do not
invalidate an unchanged reviewed inventory or executor. Independent saved-byte
replay and scoped result publication follow the observed process exit.
