# Reporting a vulnerability

Please do not post vulnerability details, credentials, private prompts or captured model data in public issues or pull requests.

Open the repository's [Security advisories](https://github.com/EastonSell/model-looking-glass/security/advisories) page and choose **Report a vulnerability** to send a private report. If that button is unavailable, open an issue titled **Request for a private security contact** without technical details or attachments. Wait for a private channel before sharing the report.

Include the release or commit, affected component, impact, and a minimal reproduction using synthetic data. List the OS, Python and dependency versions when relevant. Do not test against another person's system or data.

Reports about older releases are welcome; note whether the issue also occurs on the latest release. Fix availability and affected versions will be described in release notes or a security advisory. No response-time or backport guarantee is implied.

The app is intended for local, single-user use. Keep its server off public networks and treat saved traces as potentially private. These precautions do not make a vulnerability unreportable.
