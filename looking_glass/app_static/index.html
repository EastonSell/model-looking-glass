Checking actual device availability…

To validate this machine with tiny local synthetic models, run python -m looking_glass.app_selftest in the app environment. The JSON result distinguishes passed, failed and skipped checks; it does not use your checkpoint.

CUDA preflight and synchronized checks accompany a scoped PyTorch caching-allocator cap. A stricter existing cap is preserved and restored afterward. This is not a total-VRAM guarantee: driver/context and non-PyTorch allocations are outside it. Full captured vectors are copied to CPU RAM. CPU execution ignores this allowance.
