Model folder and installation details
      
Choose a local Hugging Face folder containing config.json, matching safetensors weights, and the matching fast tokenizer or image processor assets. For a Hugging Face cache, choose snapshots/<revision>, not a repository ID or cache parent. No automatic downloads or custom checkpoint code.

      
Install with --backend cuda for a compatible NVIDIA GPU, or --backend cpu for CPU. To change an existing installation, also pass --reuse-venv to install.py; then restart. Drivers are not installed for you.

    Supported models and limitations
      
    Eager float32: GPT-2, T5, DistilBERT masked language models, ViT image classifiers, and standard LlamaForCausalLM have CPU or single-CUDA execution paths. Auto prefers available CUDA. GPU use has been reported by the user; automated model checks ran on CPU, not GPU. Image preprocessing stays on CPU. Llama supports default or static Llama 3 RoPE only; dynamic, linear, YaRN, LongRoPE and partial rotary configurations remain unsupported. This is not support for Mistral, Qwen, multimodal descendants, quantized/GGUF checkpoints, half precision, multi-GPU sharding, or custom checkpoint code.
